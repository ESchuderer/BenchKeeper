Two bug reports against the snapshot and restore feature:

1. "When our worker restarts and calls `restore()`, our `onNodeStateChange` log fills with transitions that never happened. Restoring is not a state change: `restore()` should not call `onNodeStateChange` at all. The next `step()` reports changes as usual."
2. "Snapshots are not independent of the tree. After `const s = tree.snapshot()`, stepping the tree must not change `s`; after `restored.restore(s)`, stepping `restored` must not change `s` either. And a snapshot taken right after `restore(s)`, before any step, should equal `s` (after `JSON.parse(JSON.stringify(...))` on both)."

Fix both. Add a regression test for each report before you fix it.
