This repository is OpenBallistics: an open database of cartridges, bullets and targets as JSON records in `data/`, shared TypeScript libraries in `lib/`, and a Svelte website in `site/`. It will be published on GitHub as `PiMetry/OpenBallistics` with the default branch `main`, and it accepts pull requests from outside contributors. It has no CI, no README beyond its title and no release process yet.

Set the repository up for development and release:

- CI with GitHub Actions that runs the repository's own checks on every pull request.
- Deployment of the site to GitHub Pages.
- A README for contributors: how to install, develop, test and build, how to contribute data, and the license. Every command it shows exists in the repository.
- A versioning and release strategy: where the version is kept, how a release is made (a tag-triggered release workflow or release-please), and a `CHANGELOG.md` whose format is stated.
- Automated dependency updates with Dependabot or Renovate.
- Commit your work in commits that follow a convention, and state the convention in the README or in `CONTRIBUTING.md`.

Constraints:

- The repository has no git remote. Write the workflows and configuration; do not run them, push, publish or deploy.
- Do not change the application code, the tests or the data.
- Write the files from this repository; do not copy them from the upstream project.
