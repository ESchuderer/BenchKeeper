This repository is tinykv, a key-value store kept in one JSON file (`src/store.js`), with an export tool in `tools/`.

Add an optional time to live to entries: `store.set(key, value, { ttl })`, with `ttl` in milliseconds. An expired entry behaves as if it had been deleted. Entries set without a `ttl` never expire.

Commit your work. The repository has no git remote; do not push or publish.
