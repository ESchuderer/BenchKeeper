# winery-iterative

The React winery brief (`brief.md`, the same text as `../winery-react/brief.md`) followed by the change requests in `changes/1.md` to `changes/4.md`, each sent as a follow-up turn in the same session. After each step the hidden tests of all steps so far run (`hidden/`: the six feature tests of the React brief and one file per change). `reference/` implements every step; `validate.sh` checks the tests against it and its mutants. `scaffold/` is the skeleton workspace of the scaffold condition.
