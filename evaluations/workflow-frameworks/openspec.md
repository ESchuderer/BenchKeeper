# OpenSpec

[Repository](https://github.com/Fission-AI/OpenSpec), Category: workflow frameworks, Checked 2026-10-17, Decision: Out (setup-v3.0)

## Independent evidence

- None with a no-spec baseline.
- [harness-abc-bench](https://github.com/tonydzi/harness-abc-bench) pre-registered a Claude Code comparison (3 tasks x 3 arms, blind panel): baseline, Superpowers v6.2.0, OpenSpec v1.8.0. Spec Kit is a reserve arm. No results published as of 2026-10-14.

## Benchmark

Arms: AB (OpenSpec alone), O (with Ponytail), I, J, K, W (with a skill framework), C, D, E, Y (with a framework and the BenchKeeper layer). OpenCode arms: Q, S, U, AA. Recorded runs on Haiku 5.5 and Sonnet 5.5, one trial per arm and model, descriptive only: [winery-react](https://github.com/ESchuderer/BenchKeeper-Eval/blob/develop/bench/results/2026-10-15-winery-react.md), [cartridges](https://github.com/ESchuderer/BenchKeeper-Eval/blob/develop/bench/results/2026-10-16-cartridges.md). Arm definitions: [bench/SCENARIOS.md](https://github.com/ESchuderer/BenchKeeper-Eval/blob/develop/bench/SCENARIOS.md).

Brownfield run on Sonnet 5.5, Claude Code, k = 3 ([report](https://github.com/ESchuderer/BenchKeeper-Eval/tree/develop/bench/results)): OpenSpec alone (AB) and plain Claude Code (A) tie on the median brownfield score (85.7). With the BenchKeeper layer v3 and Matt Pocock's skills (AE) the median is 82.9. In one AE round the agent stopped after writing the proposal and implemented nothing.

## Skill authoring check

Rank 5 of 8 (tied), review 3.1, static checks 100% (generated by 1.14.1): guarded destructive steps. The same preamble in all 6 skills. Merge rules restated next to the CLI. No evaluations. Details: [bench/results/2026-10-16-skill-authoring.md](https://github.com/ESchuderer/BenchKeeper-Eval/blob/develop/bench/results/2026-10-16-skill-authoring.md).

## Decision

Out (setup-v3.0, 2026-10-17): Matt Pocock's skills keep specs and tickets in the repository's issue tracker (`docs/agents/issue-tracker.md`), so a second spec owner is not needed. Own runs, signals only:
- Openballistics brownfield, k = 3: OpenSpec alone (AB) tied plain Claude Code on the median (85.7). With the BenchKeeper layer v3 and Matt Pocock's skills (AE) the median was 82.9, and in one of three rounds the agent stopped after writing the proposal and implemented nothing.
- Cartridges, one trial per arm: OpenSpec alone ranked 8th of 29, with the highest mutation score of the arms measured (70.1%).

What it adds (one folder per change, deltas merged into `openspec/specs/` on archive, `openspec validate --strict`) still fits repositories that want per-change spec history. `setting-up-projects` keeps an existing `openspec/` when the user asks. A global OpenSpec CLI from earlier setups is removed with `npm rm -g @fission-ai/openspec` (setup-v4.0 `setup.sh` does not list it).
