# Spec Kit

[Repository](https://github.com/github/spec-kit), Category: workflow frameworks, Checked 2026-10-16, Decision: Not in

## Advertised

- Spec, plan and tasks per feature, constitution.

## Independent evidence

- [arXiv 2604.05278](https://arxiv.org/abs/2604.05278) tests Spec Kit plus the authors' own hooks: +0.15 on a 1 to 5 judge score (p<0.05), no agent-skills baseline.
- No comparison with OpenSpec found. [harness-abc-bench](https://github.com/tonydzi/harness-abc-bench) pre-registered a Claude Code comparison (3 tasks x 3 arms, blind panel): baseline, Superpowers v6.2.0, OpenSpec v1.8.0. Spec Kit is a reserve arm. No results published as of 2026-10-14.

## Benchmark

Arm: AC (Spec Kit alone). Brownfield run [mistreevous](https://github.com/ESchuderer/BenchKeeper-research/blob/main/bench/results/2026-10-18-mistreevous.md) on Sonnet 5.5, k = 3, descriptive only: median score 87.9 against 87.0 for plain Claude Code (A), at the same cost and 1.1 times the time. The agent never ran the Spec Kit tools. Arm definitions: [bench/SCENARIOS.md](https://github.com/ESchuderer/BenchKeeper-research/blob/main/bench/SCENARIOS.md).

## Skill authoring check

Rank 8 of 8, review 2.8, static checks 90% (generated by 1.2.0): no description says when to use it. A 70-line hook protocol copied into all 10 skills. Phase names differ between `speckit-tasks` and `speckit-implement`. Details: [bench/results/2026-10-16-skill-authoring.md](../../bench/results/2026-10-16-skill-authoring.md).

## Decision

Not in: overlaps the workflow's spec in the issue and tickets in the tracker (full tier), and Matt Pocock's skills when installed (setup-v3.0): `speckit-specify`, `speckit-clarify`, `speckit-plan`, `speckit-tasks` and `speckit-implement` duplicate `grilling`, `/to-spec`, `/to-tickets` and `/implement`, adding 10 skills per agent. `constitution.md` duplicates `AGENTS.md`. Needs uv on the host. Built for up-front planning per feature (one folder per feature, no merge into a current spec). BenchKeeper prefers an incremental workflow with specs and tickets in the issue tracker.
