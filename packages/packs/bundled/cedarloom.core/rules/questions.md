## Owner questions

- The open questions of a task become one issue in the hub repository `{{hub}}`, never in a product repository: labels `question`, the project's `project:<name>` label and `ready-for-human`.
- The body gives What (the topic), Impact (per option) and Why now, then the options as checkboxes (`- [ ]`). The recommended option comes first, marked "(Recommended)", with its reason, source and confidence.
- Never wait in a session for the answer. Take the recommended default when the task is clear and the default is safe and reversible, and mark it "pending owner decision" with the issue's link; otherwise push and write a handoff on that item's pull request that names the issue; the item waits, and the rest goes on.
- Use the question tool only while the user allows terminal questions.
