## Owner questions

- A question for the owner becomes an issue in the hub repository `{{hub}}`, never in a product repository: labels `question`, the project's `project:<name>` label and `ready-for-human`.
- The body gives What (the topic), Impact (per option) and Why now, then the options as checkboxes (`- [ ]`). The recommended option comes first, marked "(Recommended)", with its reason, source and confidence.
- Never wait in a session for the answer. Take the recommended default when the task is clear and the default is safe and reversible, and mark it "pending owner decision" with the issue's link; otherwise push, write a handoff on the pull request that names the issue, and stop.
- Use the question tool only while the user has allowed questions with `/cedarloom:ask`.
