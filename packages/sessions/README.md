# @cedarloom/sessions

Reads every agent session of this machine from the agent tools' own session logs (Claude Code's transcripts and Codex's rollouts), on demand: its project, agent time, tokens, cost and the result of its last test run, for the sessions board. It keeps no copy beyond a cache it can rebuild and sends nothing anywhere.

| Log                    | Where                                                                            | What counts                                                                                                                                                                                                                                                                                                      |
| ---------------------- | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Claude Code transcript | `projects/<folder>/<session>.jsonl` in the Claude Code home                      | The last `cost-state` line: Claude Code's own cost, API plus tool time and tokens per model. Without one yet (a session still running), each message's usage once, of the main transcript only, and no cost. A subagent's transcript is not read: the session's `cost-state` covers it.                          |
| Codex rollout          | `sessions/YYYY/MM/DD/rollout-*.jsonl` and `archived_sessions/` in the Codex home | Token totals of `token_count` events, priced per model at OpenAI's list prices in `src/prices.ts` (dated, marked as estimates; a model without a price, or another provider's, is named in `unpriced`); turn times of `task_complete` events. A subagent's rollout adds its tokens and cost to its root session. |

- Tests: the last test run with a readable result decides. Runs are found by tokenizing the command with `shell-quote`, heredoc bodies left out: `npm test`, `pnpm --filter x run test`, `pytest`, `go test` and the like; one behind a wrapper (`timeout 600 npm test`, `devcontainer exec ... pnpm test`) is not found. A run's exit code is its result when the run is the command's last step. Piped on (`npm test 2>&1 | tail`) or followed by another command, the summary line in the command's output is (`2 failed`, `2 errors in`, `Errors  1 error`, `11 passed`), a later command's line such as `1 failing` from `gh pr checks` included. A run without a readable result, or one that never ran, leaves the earlier result. Codex records command results only in its paginated history mode, so its sessions in the default mode show none.
- Project: the main worktree of the repository the session's folder is in, read from the `.git` entries as git reads them (a `.git` file only as a regular file of at most 1 MiB), without running git, else the folder (also when its `.git` is one git refuses, where git stops looking too).
- Cache: one JSON file of summaries (no message text but the session title) for the logs that still exist, re-read when a log's size or modification time changes. Deleting it loses only the project of a session whose worktree is gone since: that one then counts under its folder.
- Formats: both tools' log formats are undocumented. The Claude Code fixtures are two recorded sessions (Claude Code 2.1.316), scrubbed; the Codex fixtures are built from the rollout types in openai/codex at commit 8703d32b and are unverified against a recorded rollout. Whether Codex's `input_tokens` include the cache writes is unverified; the estimate assumes it.
- Agent time is API plus tool time summed, so parallel subagents and tools can make it longer than the session.
